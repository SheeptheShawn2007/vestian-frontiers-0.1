Vestian Frontiers

A tower defense game built in Unity (C#), currently a demo

## About
Tower defense game where you can spawn towers, upgrade them to their various paths (current upgrade depth goes to tier 3 with tier 1 being the ones you deploy). Currently its about protecting a gate from various dinosaurs that try to run past you

## Features
Features 1 deployable tower with 2 branches (planned 3 branches), each branch currently has 2 upgrades (planned 3 upgrades).
DoT and stun feature is available.

DO NOT USE THE TESLA UPGRADE IT WILL CRASH

## Tech Stack
- Engine: Unity
- Language: C#
